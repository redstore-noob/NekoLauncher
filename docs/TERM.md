# NekoLauncher 数据与遥测条款（TERM）

> 本文件是 NekoLauncher 关于**用户数据与网络上传行为**的承诺性条款。
> 任何版本的 NekoLauncher 在引入或修改任何涉及数据上传的功能（含遥测、统计、崩溃报告、在线服务等）时，都必须遵守本文件。
> 本文件与 Apache-2.0 许可证并行生效：许可证约束代码的使用与分发，本文件约束**项目自身对用户数据的行为**。

## 1. 核心承诺

1. **默认零遥测**。NekoLauncher 默认不上传任何用户数据。默认状态下，程序产生的网络请求仅限于下载用户主动请求的资源（游戏版本、Mod、Java 等）与查询公开数据源（版本清单、MC百科译名、在线资源列表）。
2. **不知情上传 = 违规**。任何未被本文件描述、且未在界面上明确告知用户的上传行为，都视为违反本条款的缺陷，一经发现按最高优先级修复并公告。
3. **遥测必须显式加入（Opt-in）**。未来若引入任何统计或遥测功能：
   - 必须默认**关闭**；
   - 必须在设置页提供独立、清晰、随时可关的开关，并用用户所用语言说明收集内容与用途；
   - 必须在首次开启前展示收集清单，不允许"同意一次、永久生效、内容随意扩展"；
   - 收集范围发生实质变化时必须重新征得同意。
4. **不允许静默新增上传**。版本更新说明（Release Notes）中必须披露任何新增的网络上传行为；仅修改上传目标但不改变行为的维护性变更也应在更新说明中注明。

## 2. 永远禁止上传的数据

无论用户是否同意，以下数据**不得**被 NekoLauncher 本体收集或上传：

- 微软账户令牌、刷新令牌及任何登录凭据；
- 用户名以外的账户相关信息（邮箱、皮肤私有数据等）；
- 游戏内聊天记录、世界存档、截图等用户创作内容；
- 电脑上的文件路径清单、浏览记录等与启动器功能无关的个人信息；
- 硬件指纹、持久化设备标识符等可用于跨站追踪用户的标识。

## 3. 若未来引入遥测：允许收集的上限

在用户显式开启的前提下，遥测允许的范围上限为：

- **聚合统计**：启动次数、启动器版本、操作系统与架构大类（如 Windows x64）、界面语言；
- **功能使用计数**：某功能被使用的次数（不带任何参数内容）；
- **匿名崩溃报告**：错误堆栈与启动器版本（上传前必须过滤掉本机路径中的用户名等个人信息）。

不允许的：精确到个人的行为轨迹、时间线画像、与第三方账户体系关联的数据拼接。

## 4. 现有网络行为披露

截至本文件撰写时，NekoLauncher 会访问的外部服务及其用途：

| 服务 | 用途 | 上传内容 |
| --- | --- | --- |
| Mojang / 微软 | 版本清单、版本下载、账户登录 | 登录时按微软 OAuth 流程交换令牌（不出启动器与微软之间） |
| Modrinth（含镜像） | 资源搜索与下载 | 搜索关键词与下载请求 |
| CurseForge | 资源搜索与下载（需用户自行配置 Key） | 搜索关键词与下载请求 |
| MC百科（mcmod.cn） | 模组中文名查询 | 规范化后的模组关键词（不含个人信息） |
| Hitokoto 等公开接口 | 主页小组件的公开数据展示 | 仅普通 GET 请求 |

除上表与用户显式同意的功能外，NekoLauncher 不应有任何其它上传。插件的内容不在本文件保证范围内，但项目要求插件开发者遵守同等原则（见第 6 节）。

## 5. 本地数据的归属

- 启动器的全部本地数据（配置、缓存、实例、账户令牌缓存）存放在用户可访问的存储目录中，属于用户本人；
- 用户卸载启动器后，这些数据不会被远程保留任何副本（启动器本身从未上传过它们）；
- 用户删除存储目录即等同于完全清除本地数据。

## 6. 插件与第三方内容

- 插件运行在用户设备上，其网络行为由插件开发者负责；
- 项目要求插件：不得在用户不知情的情况下上传数据，不得收集第 2 节所列数据；
- 插件市场/内置插件列表的收录标准包含本原则，违规插件会被下架。

## 7. 条款的修订

- 对本文件的任何修订必须在 Release Notes 中说明修订点；
- 放宽收集范围的修订（如新增遥测维度）不追溯适用于已关闭相应开关的用户；
- 本文件与实际行为不一致时，以"更保护用户"的一方为准，并视为需要立即修复的不一致。
